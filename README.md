# Maddy's Math Party 💖

A playful addition & subtraction game for a six-year-old, with love from Uncle Matt.

**▶︎ Play it:** https://mvprice3.github.io/maddy-math-party/

## What it is
- Four worlds to pick from: **Dream Doll Studio**, **Surprise Ball Party**, **Squishy Dumpling Café** and **Callie's Puppy Park**.
- Rounds of 10 questions with picture counters, big tap-to-answer bubbles, read-aloud, confetti and a sticker book to fill.
- Starts with numbers up to 12; a grown-up can raise the limit (up to 100) behind a "hold for 2 seconds" settings gate.
- Works on iPhone, iPad and Windows computers. Add it to the iPhone/iPad Home Screen for a full-screen app.

## How it's built
One static page — `index.html` (HTML, CSS and plain JavaScript), no install, no server. Sounds are made in the browser and the voice uses the device's built-in speech. Progress is saved only on the device (`localStorage`); nothing is sent anywhere.

- `PRD.md` — product requirements
- `MEMORY.md` — project log and decisions
- `icon-*.png`, `manifest.webmanifest` — app icon and install info
